# Plot average restoration time (minutes) per day

Plot average restoration time (minutes) per day

## Usage

``` r
plot_daily_avg_restoration(daily_df, start_date = NULL, end_date = NULL)
```

## Arguments

- daily_df:

  A daily summary data frame.

- start_date:

  Optional start date.

- end_date:

  Optional end date.

## Value

A ggplot object.
