# Filter a weekly summary by date range

Filter a weekly summary by date range

## Usage

``` r
filter_weekly_range(df, start_week = NULL, end_week = NULL)
```

## Arguments

- df:

  A weekly summary data frame with outage_week.

- start_week:

  Optional start week (Date or coercible).

- end_week:

  Optional end week (Date or coercible).

## Value

Filtered data frame.
