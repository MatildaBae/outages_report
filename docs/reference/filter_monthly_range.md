# Filter a monthly summary by date range

Filter a monthly summary by date range

## Usage

``` r
filter_monthly_range(df, start_month = NULL, end_month = NULL)
```

## Arguments

- df:

  A monthly summary data frame with outage_month.

- start_month:

  Optional start month (Date or coercible).

- end_month:

  Optional end month (Date or coercible).

## Value

Filtered data frame.
