# Plot percent momentary events per day

Plot percent momentary events per day

## Usage

``` r
plot_daily_pct_momentary(daily_df, start_date = NULL, end_date = NULL)
```

## Arguments

- daily_df:

  A daily summary data frame.

- start_date:

  Optional start date.

- end_date:

  Optional end date.

## Value

A ggplot object.
