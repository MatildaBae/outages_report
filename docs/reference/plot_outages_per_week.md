# Plot outages per week

Plot outages per week

## Usage

``` r
plot_outages_per_week(weekly_df, start_week = NULL, end_week = NULL)
```

## Arguments

- weekly_df:

  Weekly summary output from summarise_weekly_outages().

- start_week:

  Optional start week.

- end_week:

  Optional end week.

## Value

A ggplot object.
