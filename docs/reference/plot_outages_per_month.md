# Plot outages per month

Plot outages per month

## Usage

``` r
plot_outages_per_month(monthly_df, start_month = NULL, end_month = NULL)
```

## Arguments

- monthly_df:

  Monthly summary output from summarise_monthly_outages().

- start_month:

  Optional start month.

- end_month:

  Optional end month.

## Value

A ggplot object.
