# Plot customer-hours lost per month

Plot customer-hours lost per month

## Usage

``` r
plot_customer_hours_monthly(monthly_df, start_month = NULL, end_month = NULL)
```

## Arguments

- monthly_df:

  Monthly summary output from summarise_monthly_outages().

- start_month:

  Optional start month.

- end_month:

  Optional end month.

## Value

A ggplot object.
